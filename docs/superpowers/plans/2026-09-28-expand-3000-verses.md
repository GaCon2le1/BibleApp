### Curation rules (learned in the last three expansions)

A verse is **rejected** if any of these hold:

1. Its id is already selected (`lookup` flag `selected`).
2. KJV or BSB ends with `,` or a dash, or BSB starts lowercase (`lookup` flag `fragment`). The exception is a sentence that still reads complete on a card. KJV colons and semicolons are normal and fine. A BSB line with no final punctuation is acceptable only when it reads as a complete sentence.
3. It needs a specific antecedent to make sense ("He", "these things", "this man" with no referent inside the verse). A context sentence can set a scene, but a card whose main subject is an unnamed "he" or "they" fails.
4. It is one of these near-repeats of a selected verse:
   - a synoptic parallel;
   - a psalm refrain repeated in the same psalm;
   - a psalm line duplicated in 1 Chronicles 16 or 2 Samuel 22;
   - a Samuel/Kings/Chronicles parallel;
   - a prophet restating his own teaching elsewhere (e.g. `EZK.33.16` vs `EZK.18.22`);
   - an OT line that a selected NT verse quotes, or the reverse.
5. Its KJV **or BSB** text scores ≥ 0.5 Jaccard against any selected verse in the projection report, and a human reading confirms it would feel like a repeated card.
6. It is a genealogy, measurement, list fragment, or a verse whose second half is a curse or rebuke that ruins it standalone.
7. Its CPDV counterpart is the same CPDV verse already mapped to another selected id (CPDV merged two KJV verses).
8. No single CPDV verse carries its content, because CPDV splits it, reverses its meaning or loses its point. Also rejected: its CPDV display text ends mid-clause with no punctuation. Examples dropped last round: `JHN.12.24`, `1PE.2.23`, `PSA.73.22`, `PSA.130.6`, `ACT.28.2`, `PSA.125.1`, `PSA.71.18`.
9. Job's friends (Eliphaz, Bildad, Zophar) are rebuked by God in Job 42:7. Reject their lines unless they read as sound devotionally on their own; conditional promises built on the charge that Job sinned always fail.

Tier guide:
- **Tier 1:** a line most newcomers would recognise out of context. Expect ≤ 5 new.
- **Tier 2:** a strong standalone devotional line.
- **Tier 3:** good, but needs its context sentence to land.

The last batch landed at tiers 2 / 276 / 222, averaging 1.63 topics per verse.

Create `.superpowers/sdd/expand3000/projection.py`:

```python
import collections, json, pathlib, sys
sys.path.insert(0, "tools")
from curation_tools import Sources, lookup, near_duplicate_pairs, selected_ids

staging = pathlib.Path(sys.argv[1])
TARGETS = {"doubt": 370, "anxiety": 370, "forgiveness": 370, "gratitude": 370,
           "peace": 375, "grief": 390, "worth": 395, "guidance": 405,
           "strength": 405, "love": 440, "purpose": 465}
HOPE_CEILING = 570
BOOK_CEILINGS = {"PSA": 50, "PRO": 15, "ISA": 15, "ACT": 20, "JHN": 15,
                 "MAT": 15, "LUK": 15}
picks = [l.split() for l in (staging / "picks.tsv").read_text().splitlines() if l.strip()]
ids = [p[0] for p in picks]
sel = json.loads(pathlib.Path("data/curation/selection.json").read_text())["selected"]
topics = collections.Counter(t for e in sel for t in e["topics"])
topics.update(t for p in picks for t in p[2].split(","))
print("picks:", len(ids), "unique:", len(set(ids)))
print("tiers:", dict(collections.Counter(p[1] for p in picks)))
for t, floor in TARGETS.items():
    print(f"  {t:12} {topics[t]:4}  target >= {floor}  {'OK' if topics[t] >= floor else 'SHORT'}")
print(f"  {'hope':12} {topics['hope']:4}  ceiling <= {HOPE_CEILING}  "
      f"{'OK' if topics['hope'] <= HOPE_CEILING else 'OVER'}")
books = collections.Counter(i.split(".")[0] for i in ids)
for book, ceiling in BOOK_CEILINGS.items():
    print(f"new {book}: {books[book]} (ceiling {ceiling})  "
          f"{'OK' if books[book] <= ceiling else 'OVER'}")
print("new per book:", dict(sorted(books.items())))
sources = Sources()
for row in lookup(ids, sources):
    if row["flags"]:
        print("FLAG", row["id"], row["flags"], "|", row["bsb"])
new = set(ids)
for name, index in (("KJV", sources.kjv), ("BSB", sources.bsb)):
    texts = {}
    for vid in selected_ids() + ids:
        b, c, v = vid.split(".")
        key = (b, int(c), int(v))
        if key in index:
            texts[vid] = index[key]
    for score, a, b in near_duplicate_pairs(texts, threshold=0.5):
        if a in new or b in new:
            print("NEAR-DUP", name, score, a, b)
```

- [ ] **Step 2: Resolve every REVIEW line by reading**

For each `REVIEW` id, compare the BSB/KJV text (`lookup`) with the CPDV candidate and best. Choose the CPDV verse that carries the same content. Known traps from earlier expansions:
- **Shifted numbering:** CPDV shifts +1 in Jonah 2, Haggai 2, Hosea 6 and Hosea 14. Song 2:10 is CPDV 2:12, Song 5:16 is CPDV 5:17, Song 8:6 is CPDV 8:7, and Song 8:7 is CPDV 8:8. Joshua 21 has 2 fewer verses. Daniel 4 and several Ecclesiastes 5/7 verses are shifted. `MRK.9.27` and `JHN.6.67` are one off.
- **KJV breaks followed:** the vendored CPDV follows KJV chapter breaks in Malachi 4, Joel 2–3 and Nahum 1 (`MAL.4.6`, `JOL.2.28` and `NAM.1.15` all match at the same number). Do not "correct" them to the Vulgate numbering.
- **Low Psalms scores:** in Psalms the resolver's candidate is usually right; a low score usually means Latin-flavoured wording.
- **Merged verses (rule 7) and split or reversed verses (rule 8):** you may not silently change `picks.tsv`. Leave the id out of `cpdv_refs.json` and report it, and the controller arranges a screened replacement.
- **`best` is not always right.** Always read.

**Interfaces:**
- Consumes: `picks.tsv` from Task 1.
- Produces: `contexts.tsv`, one `ID<TAB>sentence` line per pick, in `picks.tsv` order.

Match the style of the 2500 existing entries in `data/curation/contexts.json`:
- **What to write:** one sentence that sets the scene: who is speaking, to whom, in what situation. Example: `ISA.41.10` → "Speaking to a fearful, exiled people, Isaiah delivers this reassurance from God not to be afraid, because God will hold them up."
- **What to avoid:**
  - Do not preach or explain the verse's meaning, and do not restate the verse.
  - Do not quote other verse numbers.
  - Do not give away the next card (e.g. "…a prayer God answers with a question").
- **Style:** plain modern English, with straight apostrophes for inner quotes ('my son'). Write "the Lord", never "the LORD". Use US spelling ("traveling").
- **Speaker names:**
  - "the Preacher" (Ecclesiastes)
  - "Solomon" (Proverbs 1–24)
  - "King Hezekiah's scribes" copying Solomon's sayings (Proverbs 25–29)
  - "King Lemuel's mother" (Proverbs 31)
  - "the writer of Lamentations"
  - "the writer of Hebrews"
  - "the psalm's writer" (anonymous psalms)
- **Psalm authors,** from the superscriptions:
  - David: 3–9, 11–32, 34–41, 51–65, 68–70, 86, 101, 103, 108–110, 122, 124, 131, 133, 138–145
  - Asaph: 50, 73–83
  - Sons of Korah: 42, 44–49, 84–85, 87–88
  - Solomon: 72, 127
  - Ethan: 89
  - Moses: 90
  - Everything else is anonymous.

  Use a superscription's occasion when there is one.
- **Neighbouring cards:** each input entry lists the existing contexts of already-selected verses within 3 verses of the pick. The new context must read clearly differently from them, with a different opening and a different angle, and must not repeat their scene description word for word.
- **Length:** 60–220 characters, aiming for 100–150.

- [ ] **Step 1: Build the five input files**

```bash
python3 - <<'EOF'
import json, sys
sys.path.insert(0, "tools")
from curation_tools import Sources
d = ".superpowers/sdd/expand3000/"
s = Sources()
existing = json.load(open("data/curation/contexts.json"))
picks = [l.split() for l in open(d + "picks.tsv") if l.strip()]
for part in range(5):
    with open(d + f"ctx_input_{part + 1}.txt", "w") as f:
        for i, (vid, tier, topics) in enumerate(picks[part * 100:(part + 1) * 100], part * 100 + 1):
            b, c, v = vid.split("."); c, v = int(c), int(v)
            f.write(f"### {i}. {vid} tier={tier} topics={topics}\n")
            for vv in range(max(1, v - 4), v):
                if (b, c, vv) in s.kjv:
                    f.write(f"   (v{vv}) {s.bsb[(b, c, vv)]}\n")
            f.write(f"   >>> BSB: {s.bsb[(b, c, v)]}\n   >>> KJV: {s.kjv[(b, c, v)]}\n")
            if (b, c, v + 1) in s.kjv:
                f.write(f"   (v{v + 1}) {s.bsb[(b, c, v + 1)]}\n")
            for vv in range(v - 3, v + 4):
                other = f"{b}.{c}.{vv}"
                if vv != v and other in existing:
                    f.write(f"   EXISTING CONTEXT {other}: {existing[other]}\n")
print("ok")
EOF
```

In these files the header is `### N. ID tier=… topics=…`, so the id is `line.split()[2]`.
